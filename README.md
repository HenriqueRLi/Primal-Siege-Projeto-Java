
# Primal Siege

Primal Siege é um jogo do gênero Tower Defense inspirado
no universo Pokémon, desenvolvido em Java utilizando
Programação Orientada a Objetos (POO) e o framework FXGL.

## Objetivo

Defender a base contra 60 ondas de inimigos, construindo,
evoluindo e posicionando torres estrategicamente.

## Funcionalidades

- 60 ondas com dificuldade progressiva.
- 25 espécies de inimigos.
- 12 ondas com chefes.
- 4 tipos de torres, com 3 níveis de evolução.
- Habilidades especiais: queimadura, lentidão,
  descarga elétrica e hidro bomba.
- Sistema de economia, construção e venda de torres.
- Telas de vitória, derrota e pausa.

## Tecnologias utilizadas

- Java 25
- JavaFX
- FXGL 25
- Maven

## Como executar

1. Instale o JDK 25 e o Maven.
2. Abra o projeto em uma IDE compatível com Java.
3. Aguarde o carregamento das dependências do Maven.
4. Execute a classe TesteFXGL.java, localizada no
   pacote primalsiege.

## Controles

- Mouse: construir, selecionar, evoluir e vender torres.
- H: recolher ou expandir a HUD.

## Conceitos de POO aplicados

- Abstração
- Encapsulamento
- Herança
- Polimorfismo

## Projeto acadêmico

Projeto desenvolvido para a disciplina de Programação
Orientada a Objetos do curso de Engenharia da Computação
da PUC-Campinas.

Pokémon e seus personagens pertencem aos respectivos
detentores de direitos. Este projeto possui finalidade
exclusivamente acadêmica.
